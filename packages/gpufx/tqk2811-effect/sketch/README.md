# Sketch

Pencil sketch: dark edges and cross-hatching on paper.



| Parameter | Default | Meaning |
|---|---|---|
| `strength` | 1.0 | Darkness of the pencil lines |
| `hatching` | 0.5 | Strength of the hatching in dark areas |
| `spacing` | 4 | Distance between hatching lines in pixels |
| `ink` | "#2a2a2e" | Pencil color |
| `paper` | "#f7f5ef" | Paper color |
| `colored` | 0 | Keeps some of the picture's colors |
| `amount` | 1 | Strength: 0 is the original picture, 1 the full effect |

# Thermal

Thermal camera: brightness becomes a heat palette from cold blue through purple, red and yellow to white.

| Parameter | Default | Meaning |
|---|---|---|
| `amount` | 1 | Strength: 0 is the original picture, 1 the full effect |
| `contrast` | 1.2 | Spread of the palette around middle brightness |
| `blur` | 1.5 | Softness, as thermal sensors have few pixels |

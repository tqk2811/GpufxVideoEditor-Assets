# Night Vision

Night vision goggles: green phosphor, brightened shadows, grain, a round vignette and faint scan lines.

The grain changes 24 times a second on the timeline clock.

| Parameter | Default | Meaning |
|---|---|---|
| `amount` | 1 | Strength: 0 is the original picture, 1 the full effect |
| `gain` | 1.8 | Brightening of the picture |
| `noise` | 0.12 | Grain, changing every frame |
| `vignette` | 0.8 | Darkening outside the round view |
| `tint` | "#5cff6a" | Phosphor color |

# Bleach Bypass

Bleach bypass: low saturation, high contrast and silvery highlights, as when a film skips the bleach bath.

| Parameter | Default | Meaning |
|---|---|---|
| `amount` | 1 | Strength: 0 is the original picture, 1 the full effect |
| `contrast` | 1.1 | Contrast of the silver layer |
| `saturation` | 0.45 | Color left in the picture |

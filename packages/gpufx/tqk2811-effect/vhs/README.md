# VHS

VHS tape: color fringes, wobbling lines, a rolling tracking band, noise and scanlines.

The band and wobble follow the timeline time.

| Parameter | Default | Meaning |
|---|---|---|
| `wobble` | 1.0 | Sideways wobble of the lines |
| `chroma` | 0.004 | Red/blue fringe offset, part of the frame width |
| `tracking` | 0.6 | Strength of the rolling tracking band |
| `noise` | 0.05 | Static noise |
| `scanlines` | 0.5 | Darkening of every other line |
| `saturation` | 0.85 | Color saturation |

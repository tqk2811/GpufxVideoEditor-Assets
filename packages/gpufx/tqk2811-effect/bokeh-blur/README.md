# Bokeh Blur

Lens blur with round bokeh: out of focus highlights spread into bright discs.

| Parameter | Default | Meaning |
|---|---|---|
| `radius` | 0.02 | Disc radius, part of the frame height |
| `highlights` | 2.0 | Boost of the bright parts, which makes the discs stand out |
| `threshold` | 0.7 | Brightness where the boost starts |

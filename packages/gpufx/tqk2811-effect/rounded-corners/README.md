# Rounded Corners

Rounds the corners of the clip and adds an optional border and a soft glow or shadow around it.

Outside the rounded box the picture is transparent, so the tracks below show through. With a dark glow color the glow reads as a drop shadow.

| Parameter | Default | Meaning |
|---|---|---|
| `radius` | 0.06 | Corner radius, part of the frame height |
| `inset` | 0.04 | Margin between the frame edge and the clip, part of the frame height |
| `border` | 0.006 | Border width, part of the frame height |
| `border_color` | "#ffffff" | Border color |
| `glow` | 0.03 | Size of the glow or shadow around the clip |
| `glow_color` | "#000000b3" | Glow or shadow color (alpha sets its strength) |

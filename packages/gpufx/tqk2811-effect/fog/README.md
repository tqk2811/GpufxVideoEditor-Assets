# Fog

Drifting fog or mist: soft layered clouds that roll across the frame, thicker at the bottom.

The fog drifts on the timeline clock.

| Parameter | Default | Meaning |
|---|---|---|
| `density` | 0.6 | Thickness of the fog |
| `speed` | 0.04 | Drift speed, frame widths per second |
| `scale` | 1.0 | Size of the clouds |
| `height` | 0.6 | How high the fog reaches (1 = whole frame evenly) |
| `color` | "#d8dde3" | Fog color |
| `seed` | 1 | Changes the clouds |

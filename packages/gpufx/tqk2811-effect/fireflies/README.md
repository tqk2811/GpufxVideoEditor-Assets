# Fireflies

Fireflies: small glowing dots wander slowly over the video and pulse on and off.

Laid over the picture with a screen blend. They move on the timeline clock.

| Parameter | Default | Meaning |
|---|---|---|
| `density` | 0.5 | Part of the grid cells that hold a firefly |
| `size` | 1.0 | Size of the glow |
| `speed` | 0.5 | How fast they wander |
| `brightness` | 1.0 | Brightness of the glow |
| `color` | "#d8ff6a" | Glow color |
| `seed` | 1 | Changes the pattern |

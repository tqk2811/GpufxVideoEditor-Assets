# Teal & Orange

Teal and orange grade: shadows lean to teal, skin tones and highlights to orange.

A split toning look in the style of action film grades.

| Parameter | Default | Meaning |
|---|---|---|
| `amount` | 1 | Strength: 0 is the original picture, 1 the full effect |
| `strength` | 0.6 | How far the colors are pushed |
| `shadow` | "#0f7c8c" | Color the shadows lean to |
| `highlight` | "#ff9a4a" | Color the highlights lean to |
| `contrast` | 1.1 | Contrast around middle gray |

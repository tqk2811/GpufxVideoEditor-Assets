# Fireworks

Fireworks: rockets burst into rings of falling, fading sparks across the sky.

Laid over the picture with a screen blend; it shows best over dark footage. Bursts follow the timeline clock.

| Parameter | Default | Meaning |
|---|---|---|
| `rate` | 1.2 | Bursts per second |
| `size` | 0.25 | Burst radius, part of the frame height |
| `brightness` | 1.6 | Brightness of the sparks |
| `height` | 0.55 | Lowest burst position, 0 = top, 1 = bottom |
| `seed` | 1 | Changes the bursts and colors |

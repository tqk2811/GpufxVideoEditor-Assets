# Tilt Shift

Tilt shift miniature: a sharp band across the frame with growing blur above and below, plus a saturation boost.

| Parameter | Default | Meaning |
|---|---|---|
| `focus` | 0.55 | Height of the middle of the sharp band, 0 = top, 1 = bottom |
| `width` | 0.15 | Half height of the sharp band |
| `falloff` | 0.3 | Distance over which the blur grows to full |
| `blur` | 4 | Largest blur (mip level) |
| `angle` | 0 | Tilt of the band in degrees |
| `saturation` | 1.3 | Color saturation, for the toy look |

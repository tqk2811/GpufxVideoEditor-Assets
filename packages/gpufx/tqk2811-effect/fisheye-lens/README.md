# Fisheye Lens

Fisheye lens: the middle bulges out and the edges bend, with an optional dark rim.

| Parameter | Default | Meaning |
|---|---|---|
| `strength` | 0.6 | Bulge (negative values pinch instead) |
| `center` | [0.5, 0.5] | Center of the lens, 0..1 of the frame |
| `zoom` | 1.0 | Zoom to hide the bent edges |
| `rim` | 0.3 | Darkening at the edge of the lens |

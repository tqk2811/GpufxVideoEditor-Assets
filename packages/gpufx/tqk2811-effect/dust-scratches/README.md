# Dust & Scratches

Dust specks, hairs and vertical scratches that jump around from frame to frame, as on a worn film print.

The marks jump to new places `fps` times a second on the timeline clock.

| Parameter | Default | Meaning |
|---|---|---|
| `dust` | 0.5 | Amount of dust specks |
| `scratches` | 0.5 | Amount of vertical scratches |
| `opacity` | 0.7 | Visibility of the marks |
| `fps` | 12 | How often the marks jump |
| `color` | "#1a1612" | Color of the marks (light colors give white dust) |
| `seed` | 1 | Changes the pattern |

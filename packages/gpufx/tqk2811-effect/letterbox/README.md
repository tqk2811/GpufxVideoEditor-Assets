# Letterbox

Cinema bars: covers the top and bottom (or the sides) so the picture shows at a wide film ratio.

A frame wider than `ratio` gets bars at the sides instead.

| Parameter | Default | Meaning |
|---|---|---|
| `ratio` | 2.39 | Width / height of the picture left between the bars (2.39 is cinemascope) |
| `progress` | 1 | How far the bars have slid in: 0 none, 1 full; animate it with keyframes |
| `offset` | 0 | Moves the open part up (negative) or down, part of the bar size |
| `softness` | 0 | Soft edge of the bars, part of the frame height |
| `color` | "#000000" | Bar color; its alpha makes the bars see-through |

# Posterize

Posterize: each color channel is cut down to a few flat steps, like a screen print.



| Parameter | Default | Meaning |
|---|---|---|
| `levels` | 5 | Steps per color channel |
| `gamma` | 1.0 | Moves the steps towards the shadows (above 1) or the highlights (below 1) |
| `amount` | 1 | Strength: 0 is the original picture, 1 the full effect |

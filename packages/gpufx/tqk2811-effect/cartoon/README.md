# Cartoon

Cartoon: flat bands of color with dark ink outlines.



| Parameter | Default | Meaning |
|---|---|---|
| `levels` | 6 | Number of brightness bands |
| `saturation` | 1.25 | Color saturation |
| `edge` | 0.2 | Edge threshold: lower draws more lines |
| `edge_width` | 1.0 | Line width in pixels |
| `edge_color` | "#101010" | Line color |
| `amount` | 1 | Strength: 0 is the original picture, 1 the full effect |

# Light Leak

Light leaks: warm colored light drifts in from the edges, as from a camera that lets light in.

The light is laid over the picture with a screen blend, so it never darkens it.

| Parameter | Default | Meaning |
|---|---|---|
| `intensity` | 0.85 | Strength of the light |
| `speed` | 0.15 | How fast the light drifts |
| `size` | 0.6 | Size of the light patches, in frame heights |
| `color1` | "#ff7a2e" | First light color |
| `color2` | "#ff2e88" | Second light color |
| `seed` | 1 | Changes where the light comes from |

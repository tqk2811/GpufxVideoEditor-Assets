# Emboss

Emboss: the picture looks pressed into metal or paper, lit from one side.



| Parameter | Default | Meaning |
|---|---|---|
| `strength` | 2.5 | Depth of the relief |
| `angle` | 135 | Direction of the light in degrees |
| `distance` | 1.5 | Width of the relief edges in pixels |
| `color` | 0 | 0 is a grey relief, 1 keeps the colors |
| `amount` | 1 | Strength: 0 is the original picture, 1 the full effect |

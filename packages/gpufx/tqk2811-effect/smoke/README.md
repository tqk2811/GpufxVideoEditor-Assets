# Smoke

Smoke: soft wisps rise from the bottom of the frame, curl and thin out as they climb.

The smoke rises on the timeline clock and keeps no state, so seeking gives the same picture again.

| Parameter | Default | Meaning |
|---|---|---|
| `density` | 0.6 | Thickness of the smoke |
| `speed` | 0.08 | Rising speed, frame heights per second |
| `scale` | 1.0 | Size of the wisps |
| `height` | 0.7 | How high the smoke climbs before it fades |
| `curl` | 1.0 | How much the wisps twist |
| `color` | "#b8b8bc" | Smoke color |
| `seed` | 1 | Changes the wisps |

# Lens Flare

Lens flare: a bright light source with a glow, a streak, rays and colored ghosts across the frame.

`center` may lie outside the frame (-0.5..1.5), so the light can stand just past an edge. Animate it with the editor's keyframes.

| Parameter | Default | Meaning |
|---|---|---|
| `center` | [0.3, 0.25] | Position of the light, 0..1 of the frame ([0, 0] = top-left) |
| `intensity` | 1.0 | Brightness of the flare |
| `ghosts` | 1.0 | Strength of the colored ghosts |
| `streak` | 1.0 | Strength of the horizontal streak |
| `color` | "#ffe2b8" | Color of the light |

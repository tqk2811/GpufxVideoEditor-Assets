# Film Grain

Film grain: soft, clumped grain that is strongest in the midtones, with a chosen grain size.

Grain is lighter in the deep shadows and highlights, as on film. It follows the timeline clock.

| Parameter | Default | Meaning |
|---|---|---|
| `strength` | 0.06 | Amount of grain |
| `size` | 1.5 | Grain size in pixels |
| `color` | 0.2 | 0 = gray grain, 1 = separate grain per color channel |
| `fps` | 24 | Grain changes per second (0 = still grain) |

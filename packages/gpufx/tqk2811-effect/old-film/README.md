# Old Film

Old film reel: sepia tone, grain, flicker, scratches, dust and gate weave.

Grain, dust and scratches are a pure function of the timeline time, so seeking gives the same frame again.

| Parameter | Default | Meaning |
|---|---|---|
| `sepia` | 0.75 | Sepia tone: 0 keeps the colors |
| `grain` | 0.07 | Film grain |
| `flicker` | 0.12 | Brightness flicker between frames |
| `scratches` | 0.5 | How often vertical scratches show |
| `dust` | 0.5 | How many dust specks show |
| `vignette` | 0.5 | Darkening of the corners |
| `weave` | 1.0 | Up-and-down shake of the frame in the gate |
| `fps` | 18 | How many times a second the grain, dust and scratches change |

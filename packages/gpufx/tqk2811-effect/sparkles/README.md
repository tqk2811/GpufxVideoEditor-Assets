# Sparkles

Sparkles: four-pointed star glints that twinkle on and off over the video, more on bright parts.

Laid over the picture with a screen blend. They twinkle on the timeline clock.

| Parameter | Default | Meaning |
|---|---|---|
| `density` | 0.35 | Part of the grid cells that hold a sparkle |
| `size` | 1.0 | Size of the stars |
| `rate` | 1.5 | Twinkles per second |
| `follow` | 0.6 | 0 = anywhere, 1 = only on bright parts of the picture |
| `color` | "#fff6d8" | Sparkle color |
| `seed` | 1 | Changes the pattern |

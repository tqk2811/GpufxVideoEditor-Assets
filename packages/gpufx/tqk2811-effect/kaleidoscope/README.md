# Kaleidoscope

Kaleidoscope: the picture is folded into mirrored slices around a center, and can turn slowly.

`spin` follows the timeline clock; set it to 0 for a still pattern.

| Parameter | Default | Meaning |
|---|---|---|
| `segments` | 6 | Number of mirrored slices |
| `center` | [0.5, 0.5] | Center of the pattern, 0..1 of the frame |
| `rotation` | 0 | Turn of the pattern in degrees |
| `spin` | 10 | Turning speed, degrees per second |
| `zoom` | 1 | Zoom into the picture |
